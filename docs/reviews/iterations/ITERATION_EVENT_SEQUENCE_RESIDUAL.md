# 原始事件序列残差模型

## 目标

保持Public 0.144方案为骨架，引入固定时间网格和434维聚合特征未保留的逐事件信息：成交/委托的原始顺序、连续时间、事件间隔、真实事件mask和样本内位置。

当天提交额度已用完，因此本轮只完成训练、验证、全量推理和候选校验，不上传。

## 数据缓存

复用`features/cache`中未按时间桶聚合的32事件序列：

- Transaction：price、volume、side；
- Order：price、volume、side、order_action。

新增`features/event_cache`时间缓存：

- seconds_before_predict / 60；
- 相邻事件间隔的log缩放；
- 真实事件mask；
- 样本内事件位置。

扫描规模：

- Train Transaction：103,970,264行；
- Train Order：170,056,583行；
- Test Transaction：70,909,408行；
- Test Order：119,465,287行。

缓存已验证无NaN/Inf，有效事件按最近→较早方向单调，mask与事件数量一致。

## 模型

双路Event CNN–Transformer：

- 每路两层残差Conv1d；
- d_model64、两层Transformer；
- masked attention pool + masked mean + recent endpoint；
- 双流Cross-Transformer；
- 约0.417M参数；
- physical batch1024；
- 12 epochs；
- 固定checkpoint 6/9/12单位ensemble。

输入还包括事件价格/数量一阶差分及方向交互。

## 嵌套残差目标实验

残差标签来自每个外层训练期内部最后14个月的严格样本外基础预测。

- Proxy偏残差相关：+0.01628，10%权重全局+0.000833；
- Middle偏残差相关：+0.01785，10%权重全局+0.001018；
- Late偏残差相关：约-0.00007，任意正权重均下降。

结论：短内部窗口残差跨Late状态不稳定，不能使用。
