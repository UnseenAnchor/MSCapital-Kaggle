# 全部结果审计：Public 0.144方案

## 审计结论

当前0.144不是靠新自研模型得到的，而是：

```text
0.6 × 公开LB0.142参考预测 + 0.4 × 已实测Public0.140自研候选
```

这是当前唯一被Public直接验证的有效结构。后续优化必须提升右侧的自研0.140锚点，不能继续寻找低强度第三模型，也不能继续扫线性权重。

## 为什么前面的尝试低效

1. 把历史CV提升误当成隐藏测试提升：Joint、Residual和Event均重复了这一错误。
2. 把低相关误当成强增量：v9_big/Event证明单模Public强度是第一门槛。
3. 用诊断提交寻找未知强度：v9_big、ens5、v10、Event虽提供信息，但没有直接提高成绩。
4. 在当前0.144上做线性微调：数学空间低于显示精度，无法改变排行榜。

## 线性权重是否还有价值

已知端点中心分数和测试相关性下，公开参考+自研v3的理论最优权重约为：

- 公开参考：56.8%；
- 自研v3：43.2%；
- 理论分数：0.144691。

当前使用60/40时理论分数约0.144676，两者差异只有约0.000015。当前实际Public为0.144而不是理论中心0.14469，说明三位小数端点误差和CV/LB偏差远大于该差异。

因此不再上传邻近权重。

## 自研Stack快速审计

将已有LGB、RealMLP、v3、Joint、Event OOF按固定权重跨Proxy/Middle/Late搜索，最优粗网格权重约为：

```text
LGB 20% + RealMLP 15% + v3 20% + Joint 40% + Event 5%
```

三折全局约为0.158 / 0.156 / 0.170，表面优于单模型，但这类OOF已被17次Public结果证明会严重高估。它的测试自研预测与公开参考相关性约0.895，不能据此声称达到Top10，也不生成提交文件。

该审计只证明“已有预测线性重配”不是Top10路线；下一步必须产生真正更强的自研Public锚点。

## 重新确定的优化路线

### 冻结部分

- 冻结公开LB0.142参考的60%；
- 暂不改变当前0.144提交文件；
- 停止Event、v9_big、domain weighting、residual和joint权重搜索；
- 不再上传诊断模型。

### 唯一值得训练的部分

训练一个**真正更强的自研锚点**，目标不是残差小修，而是把自研Public0.140锚点提升到至少0.151以上：

- 保留v3高分辨率Market400/Flow120作为主干；
- 重点提升纯自研模型强度，而不是继续添加弱第三模型；
- 训练/验证必须采用跨月滚动和跨状态稳定性；
- 只在离线保守估计接近0.151–0.153时生成测试候选；
- 最终只提交一个Top10候选。

### 训练闸门

1. 相对当前自研v3锚点，Proxy/Middle/Late全局均至少+0.001；
2. 三折月均、最差月不下降；
3. 新自研锚点与公开参考相关性不高于0.92；
4. 预测强度必须足以支持自研Public至少0.151的估计；
5. 固定公开60%后，保守预估Public至少0.153；
6. 未达到以上条件，不生成提交文件。

## 最终判断

当前最优不是“再找一个低相关模型”，而是：

> 把已被Public验证的自研0.140锚点真正提升到0.151级别；公开60%保持不动。

这会把实验从“探索新方向”改为“优化已验证方向”，避免继续消耗GPU时间和提交额度。
