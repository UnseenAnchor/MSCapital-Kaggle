# 迭代复盘：全长度事件序列（Event-256）——全新信息来源

## 问题发现

审计发现 Event 模型长期被截断到 **32 个事件**：`build_cache.py` 中 `LEN_O=LEN_X=32`，
而原始 order 流中位 88、90分位306、99分位716；transaction 流中位48、90分位196、99分位495。
原 Event Transformer 只看到约1/4的委托流和约4成的成交流。

## 修复

- 新增 `src/build_event_seq_v2.py`：以 `EVENT_LEN=256` 重建完整 order/tx 事件缓存
  （features/event_cache_v2），用时约43秒；
- 实事件掩码、时间间隔、位置特征同步扩展到256；
- 训练配置不变（D64/2层/LAMBDA_COS=0.8/12轮/checkpoint 6,9,12）。
