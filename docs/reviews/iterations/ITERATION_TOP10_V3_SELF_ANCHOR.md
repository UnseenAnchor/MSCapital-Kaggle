# Top10自研v3锚点增强：v3big Proxy止损

## 目标

沿着Public0.144方案，只增强自研锚点，不再添加低强度第三模型。

目标门槛：新的自研锚点必须接近0.151–0.153，固定公开60%后才可能达到Top10显示门槛0.153。

## 配置

- v3网格：Market400 / Transaction120 / Order120；
- d_model96；
- Transformer3层；
- physical batch256 × accumulation4 = effective batch1024；
- 12 epochs；
- Proxy：month0–44训练，45–70验证；
- 不加入公开预测、Event、Residual或Joint。

原v3 d_model64/2层Proxy ensemble为0.14752，因此v3big增强版反而下降约0.0027–0.0067。

## 决策

- Proxy未通过+0.001门槛；
- 不训练Middle/Late；
- 不生成测试候选；
- 不提交；
- 停止d_model96/3层这一条架构分支。

这次实验有效排除了“简单增大v3模型容量”作为Top10路线，后续若继续，只能改变信息表征或训练目标，不能继续堆容量。
