# Multi-Resolution自研锚点

## 目标

沿着Public0.144方案，只增强自研40%锚点。输入同时保留v2和v3时间尺度：

- v2：Market200 / Flow60；
- v3：Market400 / Flow120；
- 六路独立编码 + 跨尺度Cross-Transformer；
- d_model64、每路两层；
- effective batch1024；
- 12 epochs。

固定Multi-Resolution checkpoints 5/6/7，与原v3 50/50混合。

## 三折结果

| Fold | 原v3 | Multi-Resolution 50/50混合 |
|---|---:|---:|
| Proxy | 0.14752 | **0.15348** |
| Middle | 0.14825 | **0.15079** |
| Late | 0.15995 | **0.16679** |

三折全局、月均和最差月均均提高，说明v2/v3跨尺度互补真实存在。

## 测试推理

全量训练12轮，固定checkpoint 5/6/7完成测试推理：

- Multi-Resolution与原v3测试相关性：0.84884；
- 新自研锚点与公开参考相关性：0.90325；
- 新候选与当前Public0.144相关性：0.97633。

Proxy按Train/Test对抗分数五分组：

Multi-Resolution单独模型在最像测试的20%历史样本中下降0.00307，但预注册的原v3 + Multi-Resolution 50/50混合在五个测试相似分组全部提高，最像测试组由0.14020提高到0.14393。该混合同时通过全局、月均、最差月和测试相似尾部闸门。

## 决策

- 保留原v3 + Multi-Resolution 50/50自研锚点；
- 固定Multi-Resolution checkpoints 5/6/7；
- 不扫描50/50附近权重；
- 不把候选直接称为Top10，先计算其相对公开60%骨架的保守强度；
- 若强度估计不足0.151，则继续优化自研锚点，不提交。

全量新自研锚点与旧自研锚点相关性为0.99894，原因是旧Public派生候选仍占80%。因此下一步必须替换这80%旧锚点，而不是继续微调Multi-Resolution在20%槽位中的权重。
